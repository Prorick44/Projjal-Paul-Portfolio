# ⚡ Projjal Paul - Software Engineer Portfolio

Personal developer portfolio website showcasing full-stack MERN applications, real-time collaborative coding platforms, weather analytics, competitive programming milestones, and academic qualifications.

---

## 🌟 Featured Highlights

- **Real-Time Interview Platform (CodeCollab)**: Full-stack collaborative coding environment featuring Monaco Editor, Socket.io synchronization, Firebase Google authentication, WebRTC video conferencing, and live code execution.
- **Real-Time Weather Dashboard**: Responsive weather platform covering 200,000+ cities with search debouncing, caching (40% API overhead reduction), and interactive Chart.js forecast visualizations.
- **Competitive Programming Vault**: 1,000+ solved algorithmic problems across CodeChef, LeetCode, and 20+ contests with a CodeChef 3-Star (1600+) rating (Top 10% finishes).
- **Full-Stack Web Suite**: 5+ personal projects built with React, Node.js, Express, MongoDB, MySQL, and Redux Toolkit with 90+ Google Lighthouse performance scores.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Modern CSS3, JavaScript (ES6+), React.js, Redux Toolkit, Chart.js
- **Backend & Real-Time**: Node.js, Express.js, Socket.io, WebRTC, Firebase Auth, RESTful APIs
- **Databases**: MongoDB, Mongoose, MySQL
- **Languages & DSA**: C, C++, Java, Python, JavaScript, SQL
- **Deployment & Cloud**: Vercel, Render, Git/GitHub

## 🚀 Local Setup & Preview

Clone the repository and open `index.html` directly in your browser:

```bash
git clone https://github.com/projjal2002/Projjal-Paul-Portfolio.git
cd Projjal-Paul-Portfolio
```

Or double-click `launch-portfolio.bat` on Windows.
